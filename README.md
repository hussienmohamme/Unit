# تقرير وحدة الأثر

صفحة واحدة ثابتة (index.html) بلا أي خادم أو بناء.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (يُفضَّل **Private** لأن الصفحة فيها أسماء طلاب حقيقية).
2. ارفع الملفات: `index.html` و `.nojekyll` و `README.md`.
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`

ملاحظة: Pages للمستودعات الخاصة تحتاج خطة مدفوعة. إن كان المستودع عامًا فالصفحة عامة لكل من يملك الرابط.
